# Статус проверки поставки

Дата: 17 сентября 2026.

## Подтверждённая проверка GitHub Actions

17 сентября 2026 [запуск CI](https://github.com/0rionman/NYC_Yellow_Taxi_Forecasting/actions/runs/35235805827) завершился успешно:
тесты и pip check на Python 3.11/3.13, сборка Docker и HTTP-healthcheck контейнера.
Проверялся commit cc7d6f4. Это не полный запуск обучения на TLC.
Предупреждения CI о Node.js 20 относятся к версиям служебных actions, а не к тестам проекта.

## Что проверено локально

- 23 автотеста прошли в исходной среде и повторно в новом изолированном окружении Python 3.11.
  Включены искусственный годовой эксперимент и Streamlit AppTest.
- Чистая установка из requirements.txt завершилась; `pip check`: `No broken requirements found`.
- Проверенные версии сохранены в requirements.lock.txt; Colab и Docker устанавливают этот набор.
- Streamlit запущен отдельным сервером; HTTP healthcheck вернул 200.
- Сохранение/загрузка модели и равенство прогнозов.
- Причинность признаков, сценарные задержки, обработка ошибок входа, очистка и кэш.
- Синтаксис всех ячеек и формат .ipynb проверяются при сборке.

Все искусственные данные находятся вне поставляемой папки проекта. Их метрики не являются
результатами исследования и не включены в `artifacts` поставки. Итоговый протокол тестов
записан в `test_results.txt` и `clean_test_results.txt`, фактические версии — в
`validation_environment.json` и `clean_validation_environment.json`.
Диагностические логи и описания локальной среды входят только в локальную поставку ZIP,
не публикуются в репозитории и не встраиваются в Colab notebook.
28 предупреждений чистого запуска относятся к устаревающему внутреннему API matplotlib,
используемому pandas при отрисовке; ошибок тестов нет.

## Что не следует считать завершённым

- Полное обучение версии 2 на настоящих TLC данных и новый holdout ещё не выполнены.
  Их запускает ноутбук в Colab; отчёт формируется только по рассчитанным результатам.
- Полная установка и запуск непосредственно в Google Colab ещё не проверены.
  В ноутбуке обязательны dependency check и pytest перед обучением.
  Локальное зависание установщика устранено отключением недоступного кэша; это не конфликт пакетов.
- Docker локально отсутствует; сборка и healthcheck успешно проверены в GitHub Actions.
  Работа контейнера с реальной обученной моделью ещё требует артефактов Colab.
- Целевой GitHub-репозиторий: https://github.com/0rionman/NYC_Yellow_Taxi_Forecasting.
  Состояние публикации и CI проверяются отдельно от локальных тестов.
- Прокси Streamlit внутри Colab подготовлен по API Colab, но в реальной сессии Colab не проверен.
- Фактическая онлайн-доступность очищенных лагов, бизнес-назначение и SLA требуют данных заказчика.

## Как завершить проверку

1. Выполнить ноутбук сверху вниз в свежей среде Colab CPU. Попытка скачать большой Parquet
   TLC локально завершилась тайм-аутом чтения; метрики версии 2 не выдумывались.
2. Убедиться, что dependency check и pytest завершились успешно.
3. Проверить cv_summary.csv, interval_cv_summary.csv, evaluation.csv и REPORT.md.
4. Скачать ZIP и проверить Streamlit с реальными артефактами.
5. Выполнить `docker compose up --build`; проверить healthcheck и прогноз.
6. Репозиторий опубликован в main; GitHub Actions успешно завершён (ссылка выше).
7. Не менять модель по январскому holdout без нового независимого периода.
