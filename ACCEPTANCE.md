# Соответствие критериям и границы готовности

**Реализовано** означает наличие исполняемого кода и проверок, а не заранее достигнутое
качество на TLC. Реальные выводы появляются после запуска. Обязательность — по изображению пользователя.

| № | Критерий | Состояние версии 2 / свидетельство |

| 1 | Постановка, данные и бизнес | Горизонт, прокси-таргет, NYC, источник, доступность истории описаны; бизнес-действие ещё не согласовано. |

| 3 | Визуализации | Подписанные оси и единицы; графики notebook и интерактивный Streamlit. |
| 4 | Признаки и полезность | Три набора на одинаковой календарной CV; отчёт о разнице MAE, гипотезы лагов/окон. |
| 5 | Предобработка | Пакетная очистка, аудит, DST, проверка полноты, scaler/OHE внутри Pipeline. |
| 6 | Метрики | MAE/RMSE/WAPE + асимметричная бизнес-ошибка 3/1; штрафы явно сценарные. |
| 7 | Проверка утечек | Тест изменения будущего, временные границы и задержки 1/2/24 часа. |

| 21 | Отсутствие утечек | Причинность и fit только на прошлом проверяются; фактическая доступность очищенных лагов онлайн остаётся неподтверждённой. |

## Условия окончательного закрытия проекта

- Чистая установка, pip check и все тесты в целевом окружении.
- Полный запуск TLC с неизменённым заранее зафиксированным протоколом.
- Честный разбор результата, в том числе если модель не выигрывает или интервалы не достигают номинала.
- Проверка Streamlit и Docker на скачанных реальных артефактах.
- Согласованная публикация GitHub и зелёный CI.
- Для эксплуатации: подтверждённая доступность истории, бизнес-действие и регулярное обновление/мониторинг.
